# Mewsaic Nook

A color cannon puzzle game with offline puzzles and optional network advertising for iPhone and iPad, with 200 campaign puzzles and 10 rotating daily challenges.

- Bundle ID: `com.mewsaic.erden.nook.app`
- Version: `1.1.0`
- Minimum iOS: `15.0`
- Xcode: `26.2`

Run `pod install` and open `loop_miao.xcworkspace` and select the shared `MewsaicNook` scheme.

See [CI instructions](ci/README.md) for GitHub Actions signing, IPA artifacts and App Store Connect upload.
